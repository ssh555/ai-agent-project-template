## 3. 发布门禁

- 需求、设计、实现和文档状态一致；
- 定向及联动测试通过，未执行项已明确接受；
- 候选配置、依赖、目标运行时和安装包已检查；
- 数据迁移、兼容、备份和回滚经过审核；
- Commit、Tag、制品校验值和发布人可追溯。
